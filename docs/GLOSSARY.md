# GLOSSARY — AgentHR

| Термин | Значение |
|---|---|
| **Agent Harness** | оркестратор агента: состояние, tool-calls, лимиты, логирование |
| **Tool Calling** | вызов LLM типизированных функций, исполняемых Harness'ом |
| **Knowledge Graph** | онтология тем и зависимостей + срез уровня пользователя |
| **Persistent Memory** | профиль знаний + история сессий + семантический слой |
| **Adaptive Learning** | изменение сложности и темы вопросов по ответам пользователя |
| **Gap-анализ** | «требуется вакансией − умею» → темы для подготовки |
| **Ontology v2** | 89 атомарных навыков с алиасами и 75 пререквизитами; словарь, а не фильтр |
| **Provisional-тема** | автосозданная непроверенная тема для нового навыка; ждёт approve/reject/merge |
| **Canonical-тема** | подтверждённая тема онтологии; участвует в `confirmed_readiness` |
| **MVP-core** | сквозной сценарий с реальным агентским циклом и памятью |
